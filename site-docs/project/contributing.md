# Contributing

The repository root [`CONTRIBUTING.md`](https://github.com/jssantogit/noqlen-meta-plugin/blob/main/CONTRIBUTING.md)
is canonical. It covers development installation, offline tests, opt-in live
tests, synthetic-fixture rules, strict documentation builds, hygiene, and pull
request expectations.

Never use a real music library or copyrighted audio in automated tests. Do not
put tokens, private paths, or local tool configuration in issues or commits.
