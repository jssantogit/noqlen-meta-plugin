# Getting Started

This path takes you from installation to one safe preview and one explicit
database application. It assumes only that beets is already installed and has
music in its library.

1. [Install and enable Noqlen Meta](installation.md).
2. [Preview an album and understand the result](first-preview.md).
3. Read [database, files, and Navidrome](../concepts/database-files-navidrome.md)
   before expecting another application to see database-only changes.

Noqlen previews by default. Keep the first query narrow and do not add
`--apply` until the output is understood.
